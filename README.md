## 📊 Data Repositories

Projects that involve data management, storage, API integration, and data-driven business logic.

---

### 🚚 [FreteDeCompras](https://github.com/EricPrates/FreteDeCompras)
![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)

A Java terminal application that **simulates freight calculation and delivery forecast** for an e-commerce scenario. Applies OOP principles — abstract classes, interfaces, inheritance, and encapsulation — to model different user types and calculate shipping costs programmatically.

---

### 🏋️ [FitTrack](https://github.com/EricPrates/FitTrack)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat&logo=typescript&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat&logo=supabase&logoColor=white)

A full-stack fitness tracking web app built with **Next.js + React + Supabase**. Manages user-specific workout data, exercise history, and evolution tracking with cloud database and authentication. Planned evolution into a social fitness platform with challenges and community interaction.

---

### 📍 [viacep-integration](https://github.com/EricPrates/viacep-integration)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

A React + Vite application that **integrates with the ViaCEP public API** to query Brazilian postal codes (CEPs) and automatically populate address fields. Demonstrates REST API consumption and real-time data binding.

---

### 🛒 [appVendasMobile](https://github.com/EricPrates/appVendasMobile)
![React Native](https://img.shields.io/badge/React_Native-20232A?style=flat&logo=react&logoColor=61DAFB)

A React Native mobile app that **simulates a sneaker sales system** with role-based access (admin vs. regular user). Uses LocalStorage for data persistence and covers product registration, cart management, and order simulation — a practical study in mobile data flow and state management.

---

### ✈️ [TravelPackages](https://github.com/EricPrates/TravelPackages)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

A JavaScript application focused on **managing and displaying travel packages**, exploring data listing, filtering, and presentation patterns in a web context.
